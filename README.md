# LIBREN — Brand website

Bilingual static landing page for LIBREN, an independent technology ecosystem.

- Default language: Vietnamese
- Secondary language: English (toggle in the navigation)
- Stack: semantic HTML, CSS, and vanilla JavaScript
- Hosting: GitHub Pages via GitHub Actions

## Local preview

Open `index.html` in a browser. Google Fonts are loaded from Google Fonts when online.

## Deployment

The workflow at `.github/workflows/pages.yml` deploys the repository root to GitHub Pages whenever a commit is pushed to `main`, or when manually triggered.

In the repository settings, ensure **Settings → Pages → Build and deployment → Source** is set to **GitHub Actions** if it is not configured automatically.

## Content note

LIBREN OS, AI, CLOUD, DEV, ID, and LABS are presented as ecosystem directions, not as claims that all products are currently released.
